# Eddie laptop interface

Run from the repository root:

```sh
python3.11 -m venv .venv-frontend
.venv-frontend/bin/pip install -r voice/requirements.txt
.venv-frontend/bin/python frontend/serve.py
```

Open http://localhost:5173. Click **Wake Eddie** or press **Space** to preview the character. Escape dismisses him. Mouth animation follows the duration of macOS local speech output. No browser speech-recognition service is used.

## Local “Hey Eddie”

Download https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip once and unpack it into `voice/models/`. The model folder should be `voice/models/vosk-model-small-en-us-0.15/`.

Click **Enable “Hey Eddie”**, grant microphone access to the application running Python in macOS System Settings → Privacy & Security → Microphone, and say “Hey Eddie.” Pause, then ask a question. Audio is processed in memory locally and is not recorded. This first pass uses offline Vosk transcription to detect the phrase; it is not a trained dedicated wake-word model. Real-room accuracy must be tuned on the demo microphone.

The voice replies are intentionally limited: observed traffic totals and an explicit message that rule controls are not connected. Connect the real local agent before claiming command execution.

## Traffic contract for Claude

The browser automatically reconnects to `ws://localhost:8000/ws/events`. Override with `?traffic=ws://localhost:PORT/path`. Each message may be one event, an array, or `{ "events": [...] }`.

```json
{"timestamp":"2026-11-07T16:30:00Z","device":"Fire Stick","domain":"device-metrics-us.amazon.com","action":"block","reason":"Known telemetry","source":"blocklist"}
```

Alternative: POST the same JSON to `http://localhost:5173/api/events`. This route also supplies counts for the placeholder voice summaries. WebSocket traffic currently only populates dashboard counts. No sample traffic is generated by the frontend; label seeded/demo data at its source.

Voice lifecycle events may also arrive on the traffic WebSocket:

```json
{"type":"wake"}
{"type":"transcript","text":"What's going on?"}
{"type":"speaking","text":"I blocked three tracking requests."}
{"type":"speech_end"}
```

For a separate agent use the WebSocket events above to control the overlay, or call `window.eddie.wake()`, `window.eddie.pushEvent(event)`, and `window.eddie.voiceEvent(event)` in the page.

The server binds only to localhost for the laptop demo. External fonts, analytics, and cloud audio are not used.
